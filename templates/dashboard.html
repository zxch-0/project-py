Fonctionnement

  1. Ajoutez un fichier (.py, .js, .sh) ou un projet complet (.zip, .tar.gz, .rar, .7z).
  2. Le site analyse le code : questions, menus a choix, dependances, risques.
  3. Vous remplissez les reponses dans le formulaire, puis le script demarre.
  4. Il tourne sur le serveur : vous pouvez fermer la fenetre, l'execution continue.

Questions et menus interactifs

Si le script contient input("URL webhook : "), read -p ou un menu 1 - Demarrer / 2 - Quitter, le site les detecte et propose :

  • un formulaire avant le lancement (avec boutons de choix cliquables),
  • une console interactive pendant l'execution pour les questions restantes,
  • la relecture automatique de vos reponses au redemarrage ou via webhook.

Projets multi-fichiers

Uploadez une archive : le site l'extrait, liste les fichiers, detecte les points d'entree possibles et les manifestes (requirements.txt, package.json). Choisissez l'entree, installez les dependances (pip ou npm), puis lancez. Chaque fichier est modifiable dans l'editeur integre.

Runtimes supportes

  • Python (.py) — analyse complete, pip, verification syntaxique.
  • Node.js (.js, .mjs, .cjs) — detection des questions et paquets npm.
  • Shell (.sh) — detection des read -p et menus select.
  • Personnalise — tapez n'importe quelle commande (php, ruby, deno...) avec {file} comme script.
