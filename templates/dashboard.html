📦 Mon script a besoin de librairies (ex : requests, pandas) ?

      
Colle ton requirements.txt au moment de l'upload (ou plus tard dans la fiche du script), coche « installer les dépendances », puis démarre le script.

    

    

      
🔔 Recevoir les données du webhook dans mon script

      
Active le « déclenchement auto » et lis la variable d'environnement dans ton code :


import os, json
payload = os.environ.get("WEBHOOK_PAYLOAD", "{}")
data = json.loads(payload)
print("Webhook reçu :", data)

    

    

      
⚠️ Points importants sur Render

      
    
        
  • Sur l'offre gratuite, Render met le service en pause après ~15 min sans visite : tes scripts seraient interrompus. Pour du 24/7, passe au plan Starter (voir render.yaml).
    • 
        
  • Les fichiers (scripts, logs, code secret) sont stockés sur un disque persistant : ils survivent aux redéploiements.
    • 
        
  • Si le serveur redémarre, les scripts ne redémarrent pas tout seuls : reviens cliquer « ▶ Démarrer ». (Astuce : le webhook avec déclenchement auto peut relancer ton script à distance.)
    •
