❓ Comment ça marche ?

  1. Ajoute ton script .py (upload ou modèle).
  2. Le site le scanne 🧠 : questions input(), menus 1, 2, 3, librairies manquantes.
  3. Tu remplis les réponses dans le formulaire (ou tu réponds en direct dans la console).
  4. Le script tourne sur le serveur — ferme la fenêtre, ça continue ✔

💬 Questions & menus interactifs

Si ton script contient input("URL webhook : ") ou un menu 1 - Démarrer / 2 - Quitter, le site les détecte et te propose :

  • un formulaire avant le lancement (avec boutons de choix cliquables),
  • une console interactive pendant l'exécution pour répondre aux questions restantes,
  • la relecture automatique de tes réponses au redémarrage ou via webhook.

📦 Librairies (requests, pandas…)

Le scan détecte les imports et propose d'ajouter les paquets au requirements.txt. En cas de crash ModuleNotFoundError, un bouton « 📦 Installer » apparaît dans le diagnostic.

🔔 Webhook dans ton script

import os, json
data = json.loads(os.environ.get("WEBHOOK_PAYLOAD", "{}"))
print("Signal reçu :", data)
